### Short Description of Project

Stage 1 : tried to create a multi agent system using langgraph for speech data quality assessment. Assessment includes checking file formats and any information related to audio files. Any analysis you want to do on the audio files. Bharatgen needed a system to analyse large amount of audio data that they recieve from various vendors. A prototype was created although it was never scaled. Stage 2 working with Preeti Rao ma'am target is to improve an existing tool called TARA. It is an oral reading fluency assessor currently deployed in many KV schools. It is primarily a cascaded system of ASR system and other ML models. Our task was to find some deep learning alternative like SpeechLLMs . But to train speech LLM we are currently generating synthetic data and for that we are trying to categorise these errors made by students so as to train the model specifically to identify those kind of erros
